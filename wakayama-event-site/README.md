# わかやま日和

和歌山市・岩出市・紀の川市・海南市・有田市のイベントを探せる、静的な試作サイトです。

## 確認方法

`index.html` をブラウザで開くか、このフォルダでローカルHTTPサーバーを起動してください。

## 実装済み

- 月別・開催日順のイベント一覧
- 市／カテゴリー／キーワードによる絞り込み
- お気に入り（ブラウザ内保存）
- イベント詳細、共有、Googleカレンダー登録
- レスポンシブデザイン
- description、canonical、OGP、Twitter Card
- Schema.org `Event` 構造化データ

イベント情報は公式サイト・地域情報サイト・主催者公式Instagramを横断して確認する方針です。公開前・お出かけ前にはリンク先の最新情報を再確認してください。
